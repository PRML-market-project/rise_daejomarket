# 2026-10-29 지도 디자인 반영

원본: [Figma · 261029_지도_FULL](https://www.figma.com/design/FAR8pPnXUZCtc7GHNS5cbT?node-id=1002-72311)

- 지도 전체 영역을 9,833 × 12,973으로 확장하고, 우측·하단의 도로·건물·부지를 원본 SVG 레이어로 추가했다.
- 기존 6,807 × 10,577 배경과 점포명 아틀라스는 원래 좌표와 크기를 유지한다. 기존 지도 이미지를 늘려 빈 공간을 채우지 않는다. 점포 ID·경로·거리 계산도 유지한다.
- 불광역 노선 표기와 6·7번 출구를 Figma 원본으로 반영했다. 7번 출구는 기존 배경에 포함된 이전 위치의 표기가 중복되지 않도록 해당 영역만 마스킹했다.
- 최초 검색은 시장 중심 `(4916.5, 5637)`을 사용한다. 시장 중앙 통로 `x=4920`이 화면 중앙에 위치하고, 상단 검색 영역·하단 결과 목록·AI 안내 문구가 차지하는 공간을 제외한 지도 영역의 중앙으로 맞춘다.
- 확대·축소, 드래그, 선택한 점포·길찾기 화면도 새 지도 경계와 가려지는 영역을 사용한다.
- 어드민의 지도 코드·데이터·SVG도 `admin-frontend/scripts/sync-map-data.mjs`로 동기화했다.

에셋의 Figma 노드 ID, 원본 크기와 배치 좌표는 `frontend/ml-test-main/src/data/mapArtwork.ts`에 있다. Figma의 임시 다운로드 URL을 런타임에 사용하지 않는다.

## 검증

`frontend/ml-test-main`에서 실행:

```powershell
node scripts/test-map-artwork.mjs
node scripts/test-result-map-overview.mjs
node scripts/test-route-guidance.mjs
node scripts/test-location-marker.mjs
npm.cmd run build
```

- 새 SVG 7개의 파일 존재·원본 크기·실제 렌더 배치·어드민 사본 일치 확인.
- 세 화면 크기와 AI 안내 문구 유무에 대해 최초 검색의 중앙 배치 확인.
- 지도 밖 여백이 드러나지 않는 이동·확대 경계와 기존 길찾기·마커 회귀 검증 통과.
- 키오스크 빌드 및 어드민 `tsc --noEmit` 통과.
- 정적 렌더로 확장 배경과 지하철 표기 배치를 확인했다. 브라우저 자동화는 현재 URL을 검증하지 못해 도구가 중단했으므로 실제 브라우저에서의 최종 시각 확인은 수행하지 못했다.

정적 확인용 이미지: `artifacts/design-assets/map-20261029-implemented.png`, `map-subway-final-detail.png`. 전체 정적 미리보기에서는 렌더러가 외부 SVG `<use>` 아틀라스를 처리하지 못해 기존 점포명 레이어를 생략했다. 실제 앱에서는 기존 아틀라스와 클릭 영역을 그대로 렌더한다.
